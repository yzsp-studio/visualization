## 🇬🇧 English

Turns answers about trends, proportions, comparisons, processes, mechanisms, causality, architecture, relationships, timelines, state machines, algorithm steps, or parameter changes into visual replies you can review and run. A routing pass picks exactly one primary mode among text-only, original-image overlay, ECharts, and deterministic HTML/SVG, then loads only the references that mode needs. When a conclusion depends on the user's own image, original pixels, object positions, and proportions are preserved, and schematics are explicitly labeled as schematics. Real numbers, years, people, and technical details come only from user material or legitimate verification, and example data is labeled. It does not do maps, file attachment delivery, posters, avatars, photoreal images, or artistic illustration.

### ✨ What it does

- Routes each answer to text-only, image overlay, ECharts, or deterministic HTML/SVG
- Picks the fewest modules that measurably improve understanding
- Keeps original image pixels, object positions, and proportions when evidence depends on the user's image
- Labels every schematic as a schematic instead of passing it off as evidence
- Limits real numbers, years, and details to user material or legitimate verification, and labels example data
- No maps, posters, avatars, photoreal images, artistic illustration, or file attachment delivery
